# 诸天万界最强系统 v1.1 · 联网源码

这个公开仓库只提供记忆助手和状态栏联网版要读取的 JavaScript、CSS。它们位于 `remote/`：

- `assistant-v1.1.js`：独立记忆助手。
- `statusbar-v3.1.css`、`statusbar-v3.1-part1.js`、`statusbar-v3.1-part2.js`、`statusbar-v3.1-part3.js`：状态栏。

两个较小的联网导入 JSON **不上传 GitHub**。作者从本地的 `诸天万界最强系统-v1.1-联网导入文件/` 导入酒馆。它们使用 GitHub 提交号固定版本，通过 jsDelivr 的 Fastly 地址读取上述源码。以后上传新版 JS/CSS，复制新提交的 40 位编号，替换本地两个 JSON 里的旧编号，再导入酒馆。原版完整 JSON、世界书及其他正则也保留在作者本地。

文件来源、大小、限制与酒馆测试步骤见 [联网加载说明](联网加载说明.md)。联网加载可缩小本地导入文件，但手机仍要下载并运行同样的代码；实际卡顿改善尚未在酒馆中验证。
