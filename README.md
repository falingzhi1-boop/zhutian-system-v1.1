# 诸天万界最强系统 · v1.1 核心 Git 库

这里跟踪当前持续维护的两个导入文件：

- `03-脚本/脚本-诸天系统-独立记忆助手-v1.1.json`：独立记忆助手。v1.1 的主要更新在这里。
- `02-正则/正则-诸天万界最强系统状态栏3_1_通用版.json`：状态栏正则。

文件名加了类别前缀，JSON 内容保持与原 v1.1 发布包完全相同。`文件校验.json` 记录两个文件的 SHA-256 值。

世界书、语音框和旧楼层正则未纳入此 Git 库。它们的分类副本在同级的 `诸天万界最强系统-v1.1-配套导入文件/`，原 v1.1 发布包和压缩包保留不动。已安装 v1.0 的用户通常只需更新记忆助手；从更早版本升级请看[安装与验收](文档/安装与验收.md)。

公开仓库地址：`https://github.com/falingzhi1-boop/zhutian-system-v1.1`。

## 联网加载试验

`remote/` 放从上述两个原版 JSON 原样拆出的 JavaScript 和 CSS，并通过 GitHub Pages 提供联网地址。两个体积更小的联网导入 JSON 放在 Git 库旁边的 `诸天万界最强系统-v1.1-联网导入文件/`，仅供本地导入酒馆，不上传 GitHub。原版 JSON 留在原位作断网回退。

生成方法、限制和验收步骤见 [联网加载说明](联网加载说明.md)。真实酒馆中的联网版尚未验证。
